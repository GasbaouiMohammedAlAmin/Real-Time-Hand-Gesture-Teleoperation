4. How files communicate

Python import / function calls WebSocket JSON Browser viewers

The JSON message

Every robot.update() sends one JSON object. Degrees, 0 = straight. Each finger is [knuckle, middle, tip]: 

{
  "thumb":  [40, 50, 60],
  "index":  [8, 5, 4],
  "middle": [6, 5, 3],
  "ring":   [80, 100, 65],
  "pinky":  [80, 100, 65]
}

robot_hand.html uses all five fingers. demo.html only reads index.

Who talks to whom

  • main.py → imports and calls robothand.py in-process (normal Python).
  • robothand.py → opens a server on port 8765 and pushes JSON.
  • viewer/*.html → connect as WebSocket clients and animate from that JSON.
  • Viewers never talk to each other. They only listen to Python.

5. Angle pipeline (inside main.py)

  1. MediaPipe / cvzone gives 21 landmarks on the hand.
  2. Each finger has 4 points (p1…p4), base → tip.
  3. We need 3 bend angles per finger (a1, a2, a3).
  4. bendAngle(a, b, c) measures the angle at joint b using vectors.
  5. Those angles are stored with setFinger, then sent with update.
a1 = bendAngle(wrist, p1, p2)   # knuckle
a2 = bendAngle(p1, p2, p3)      # middle
a3 = bendAngle(p2, p3, p4)      # tip
robot.setFinger("index", a1, a2, a3)
robot.update()

Full math walkthrough is in Part B below.

7. Quick troubleshooting

  • Viewer says waiting… — run python main.py first; keep the tab open.
  • Port already in use — another main.py is still running; stop it (Ctrl+C / kill Python).
  • No webcam — check camera permissions; try another index in VideoCapture(0).
  • Angles look wrong — face the palm to the camera; cvzone 2.x landmarks are mostly 2D.
  • mediapipe install fails — your Python version may need a newer mediapipe wheel (don’t pin an old version on 3.14).

Part B — How bendAngle works

Each finger has 4 points. What we need are the 3 joint angles for the robot.

1. A finger has 4 points

MediaPipe tracks each finger with 4 landmarks, from the base knuckle to the tip: p1, p2, p3, p4.

p1 base p2 middle joint p3 near tip p4 tip

In main.py this is the list [5, 6, 7, 8] for the index finger (and similar lists for the other fingers).

2. What we need: the 3 angles

The robot hand does not need the raw points. For each finger we only need 3 bend angles — one at each joint:

  • a1 — base knuckle
  • a2 — middle joint
  • a3 — tip joint

Those 3 numbers are what we send with robot.setFinger(name, a1, a2, a3). 

a1 = bendAngle(wrist, p1, p2)  # knuckle
a2 = bendAngle(p1, p2, p3)     # middle
a3 = bendAngle(p2, p3, p4)     # tip
robot.setFinger("index", a1, a2, a3)

3. To measure one joint, pick 3 of those points

At every joint we take three landmarks: a (before), b (the joint), c (after).

a = point before the joint b = the joint itself c = point after the joint

4. Build two bone vectors

From those points we make two direction vectors (like two bones meeting at b): 

v1 = b - a   # bone pointing into the joint
v2 = c - b   # bone pointing out of the joint
v1 = b − a v2 = c − b θ = angle between them

5. Cosine of the angle (dot product)

The dot product of two vectors relates to the angle between them:

cos(θ) = (v1 · v2) / (|v1| × |v2|) 
cos = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2) + 1e-6)

np.dot = how aligned the bones are
np.linalg.norm = length of each bone
+ 1e-6 = tiny number so we never divide by zero

6. Convert cosine → degrees

return np.degrees(np.arccos(np.clip(cos, -1, 1)))
1
np.clip(cos, -1, 1)

Floating-point error can push cos slightly outside [-1, 1]. Clip keeps arccos happy.

2
np.arccos(...)

Turns cosine into radians (angle between the two bones).

3
np.degrees(...)

Converts radians → degrees for the robot hand.

7. What the number means

0° = perfectly straight. Larger = more bent.

Straight finger → ~0°

v1 and v2 point the same way → cos ≈ 1 → angle ≈ 0

Bent finger → large angle

Bones turn at b → cos smaller → angle bigger

Full function (from main.py)

def bendAngle(a, b, c):
    """Angle at point b in degrees. 0 = straight."""
    a, b, c = np.array(a), np.array(b), np.array(c)
    v1, v2 = b - a, c - b
    cos = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2) + 1e-6)
    return np.degrees(np.arccos(np.clip(cos, -1, 1)))

How main.py uses it

Each finger has 3 joints. For landmarks p1, p2, p3, p4:

a1 = bendAngle(lm[0], lm[p1], lm[p2])  # knuckle (wrist → base → mid)
a2 = bendAngle(lm[p1], lm[p2], lm[p3])  # middle joint
a3 = bendAngle(lm[p2], lm[p3], lm[p4])  # tip joint
